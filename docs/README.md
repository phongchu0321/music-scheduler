# Hệ thống lập lịch phát nhạc tự động

Đề tài thực tập EPCB: web platform + thiết bị Edge (ESP32) phát nhạc theo lịch.

## Cấu trúc
- `web/`: Web Platform (backend FastAPI, frontend React)
- `firmware/`: firmware Edge Device
- `docs/`: tài liệu kiến trúc, giao thức, hướng dẫn
